# Product focus and competitive position

**Reviewed:** July 31, 2026

## Honest conclusion

Falsifi cannot honestly claim to be the first investment journal, source-linked
research platform, duplicate detector, or thesis tracker. Those products
already exist.

Its narrower product task is:

> Given one stock and several research materials, identify confirmed shared
> origins, surface explainable possible overlaps, and tell the user which
> source gap to fix next.

The memorable problem is: **eight articles can still trace to one source.**

## Where it differs

Reference managers such as Zotero merge duplicate library records. Research
platforms such as Quartr and AlphaSense provide citations back to source
documents. Investment journals track theses and review dates.

Falsifi combines a smaller set of behaviors around one task:

1. canonical-link grouping that cannot be split by cosmetic URL changes;
2. cross-publisher overlap suggestions based on title, timing, event, and
   official-filing status;
3. a human confirmation loop for every approximate relationship;
4. an A-share official-announcement path through CNINFO, plus SEC EDGAR for
   U.S. filings;
5. one visible result: `materials → confirmed sources → relationships to review`.

This combination is a useful product position, not proof of global uniqueness.
Private, internal, or undocumented tools may do similar work.

## Current defensibility

The product is more useful than exact-URL deduplication alone because it now
finds explainable candidate relationships and turns the result into a next
research action. It remains reproducible by a capable competitor; the moat is
execution, provider coverage, labeled confirmation data, and increasingly
accurate provenance detection—not a secret algorithm.

## Claims we can and cannot make

Reasonable:

- “Falsifi audits the sources behind stock-research materials.”
- “Exact links are grouped automatically; approximate matches require user
  confirmation.”
- “Falsifi supports official A-share and U.S. filing discovery.”

Not reasonable:

- “world first” or “globally unique”;
- “automatically finds every copied article”;
- “proves sources are independent”;
- “proves a thesis correct”;
- “AI stock picker”; or
- “guaranteed protection from confirmation bias.”

## Next quality frontier

The largest remaining gap is full-text provenance: resolving redirects,
extracting explicit citations, and comparing factual claims across document
bodies. That should improve the one source-audit task; it should not become a
new dashboard or generic stock-analysis suite.
