# Falsifi

> **找出什么变化会推翻你的判断。**

Falsifi 是一个开源、证据优先、local-first 的投资论点压力实验室。它不生成
又一个“买入/卖出”信号，而是把研究案例变成可计算结构，主动寻找推理会在
哪里失效，并保存当时的完整状态供日后复盘。

[English README](./README.md) · [方法说明](./docs/METHODOLOGY.md) ·
[独特性审计](./docs/UNIQUENESS.md) · [数据源边界](./DATA_SOURCES.md)

在线使用：[thesis-trace.nerowan22.chatgpt.site](https://thesis-trace.nerowan22.chatgpt.site)

## v0.4 的核心能力

- **真实股票入口**：首次打开直接搜索或输入美股、A 股和港股，不再默认展示
  虚构公司。
- **带来源的行情快照**：读取一年延迟日线，显示获取时间和数据来源，并计算
  区间收益、波动率、最大回撤、RSI、均线；仅在成交量可用时生成量能证据。
  正式分析至少需要 200 个有效日度数据点。
- **可审查的自动建模**：将真实行情转为非 Demo 压力案例；自动生成的每条
  证据均可编辑，并保留上游数据链接。
- **证据独立性审计**：按共同信息源、共同主张或显式依赖关系归组，避免把
  同一消息的多次转述误当作交叉验证。
- **最小独立根翻转**：整组移除相关证据，寻找能改变研究姿态的最小已测试
  独立根集合。
- **联合翻转前沿**：在声明范围内同时改变两个假设，返回距离当前案例最近
  的多条联合翻转路径。
- **三种压力语义**：明确区分“证据缺失”“来源降级”和“出现反证”，并
  分别重新计算结果。
- **实测删项实验**：逐条移除证据并重新计算，而不是让大模型自述权重。
- **单变量临界点**：寻找跨越姿态阈值所需的最近假设变动。
- **来源组冲击与新鲜度检查**：整组删除官方申报、管理层、市场数据或外部
  估算，并标出陈旧证据。
- **本地证据账本**：可新增、编辑、停用、搜索和删除证据，无需账户。
- **可恢复 SHA-256 快照**：为规范化案例 JSON 生成本地内容指纹。它不是
  可信时间戳或防篡改账本。
- **四种界面语言**：英语、简体中文、日语和西班牙语。自动生成的案例采用
  当时所选语言；用户自己写的研究文字绝不会被静默翻译或覆盖。
- **本地优先工作区**：无需数据库、券商账户、用户账号或遥测；加载行情时
  需要联网。

## 快速运行

需要 Node.js `>=22.13.0`：

```bash
npm ci
npm run dev
```

质量检查：

```bash
npm run lint
npm run typecheck
npm test
```

生产构建：

```bash
npm run build
```

## 分析一只真实股票

1. 选择美股、A 股、港股或全部市场。
2. 搜索公司名称，或输入 `AAPL`、`603901`、`002441`、`0700.HK`
   等代码。
3. 选择公司后，Falsifi 会读取延迟日线并建立初始案例。当前仅接受至少有
   200 个有效日度数据点的上市股票；ETF、指数、期货、外汇和加密资产会被拒绝。
4. 在 **证据** 中继续加入官方申报、管理层披露或独立估算。所有行情衍生
   指标会被诚实地归为同一个来源根，不会把一个价格源伪装成多重验证。
5. 调整假设、保存快照，或导出完整案例 JSON。

内置 Yahoo Finance 图表/搜索适配器没有官方稳定 API 文档，仅适用于个人或
自托管评估，可能延迟、限流或被上游修改。若公开运营商业数据服务，应替换
为已取得展示/再分发授权的数据商。详见 [数据源边界](./DATA_SOURCES.md)。

机器可读结构在
[`data/case.schema.json`](./data/case.schema.json)，入门模板在
[`examples/case-template.json`](./examples/case-template.json)。

## 计算边界

同一份有效案例 JSON 与同一引擎版本会产生相同结果：

- 独立根翻转在最多四个根的范围内做精确枚举；
- 联合翻转在 100,000 个状态以内做穷举，超过后采用确定性降采样，并在结果
  中保留相应元数据；
- “没有找到翻转”只表示测试范围内未找到，不代表论点真实或绝对稳健。

完整公式与边界见 [`docs/METHODOLOGY.md`](./docs/METHODOLOGY.md)。

## 可选的 SEC 官方数据

SEC API 无需密钥，但必须提交带联系方式的 `User-Agent`：

```bash
export SEC_USER_AGENT="Falsifi research you@example.com"
npm run sec:fetch -- --ticker AAPL --output outputs/sec/aapl.json
```

脚本保留 XBRL 标签、单位、报告期、表格类型、accession number、提交日期和
SEC 原始链接；默认不抓交易所网站，也不重新分发第三方行情。

## 关于“独创性”

投资论点记录、场景分析、反事实解释、证据账本和 SHA-256 证据包各自都有
公开先例。Falsifi 的差异是把它们整合成一条证据优先工作流：

```text
来源依赖图 → 独立根删项 → 最小翻转
           → 联合假设前沿 → 可恢复本地版本
```

本次公开检索没有发现完全同构的开源项目，但这不等于“全球首创”。私有、
未公开和未被索引的系统无法验证。对照项目与证据见
[`docs/UNIQUENESS.md`](./docs/UNIQUENESS.md)。

## 明确不做什么

- 不提供个性化投资建议或适当性判断
- 不给出买入/卖出评级或目标价
- 不连接券商或自动交易
- 不承诺收益、准确率或 alpha
- 不把研究分数包装成客观概率
- 不用自动翻译覆盖用户的原始研究文字
