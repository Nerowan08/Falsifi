# Falsifi

> **查清股票材料的真正来源。**

Falsifi 是一个开源的股票材料来源审计工具。它只解决一个问题：
**你收集的这些材料，到底建立在多少个原始来源上？**

## 它解决什么问题

十篇看似不同的文章，可能都在转述同一份财报、采访、新闻稿或数据。
只数链接，会高估研究材料的独立性。

Falsifi 直接给出：

```text
12 份材料 → 3 个已确认来源 → 2 组关系待确认
```

然后告诉你下一步该做什么：核对原文、确认可能同源的材料、补一个独立来源，
或寻找可能反驳当前判断的材料。

## 怎么用

1. 选择一只 A 股、港股或美股。
2. 一次粘贴最多 12 个公开网页。工具会读取页面，提取精简的正文指纹和引用链接。
   也可以搜索指定公开来源，或手动添加一个链接。
3. 打开原文核对，再标记为“已核对”。
4. 检查“可能同源”的提示。是否归组由你决定。
5. 按结果中的“下一步”补齐材料。

写股票判断是可选的。写了之后，可以把材料标为“支持”“反驳”或“未设置”。

## 哪些事情会自动做

- 完全相同的规范化链接会自动归组。跟踪参数、页面锚点、域名大小写、`www`
  和末尾斜杠不会制造假的独立来源。
- 工具会读取公开 HTML 网页，但不保存整篇文章，只保留精简的正文指纹和链接。
- 公开网页如果阻止自动读取，链接仍会保留，并明确标为“无法自动读取”，不会假装分析过。
- 直接引用、共同指向同一原始材料、正文大段重合时，会给出说明原因的待确认提示。
- 标题高度相似、发布时间接近的材料会出现待确认提示。
- 新闻和公司公告在时间与事件上重合时，会出现待确认提示。
- 美股公司文件来自 SEC EDGAR，A 股公告来自巨潮资讯，Yahoo Finance 只作补充。

模糊匹配**不会自动合并**。每个提示都会说明原因，用户可以选择“归为同一来源”
或“保持独立”。

## 它不做什么

Falsifi 不预测股价，不荐股，不算目标价，也不判断你的观点一定正确。
来源归组只描述当前记录里已确认的来源关系，不代表材料一定真实、准确或编辑独立。

## 语言与隐私

界面和教程支持英语、简体中文、日语和西班牙语。审计记录保存在浏览器中。
Falsifi 没有账号、埋点、券商连接，也不使用 OpenAI API。

搜索公开材料时，只会把股票身份和用户看到的搜索词发送给页面中注明的公开数据源。
批量审计时只读取用户粘贴的公开链接。不会发送用户写的判断，不会登录、绕过付费墙，
也不会访问内网地址。
