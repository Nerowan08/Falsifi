# Falsifi

> **查看一项股票判断的材料如何按来源归组。**

Falsifi 是一个开源的股票研究材料整理工具。选择一只上市股票，可以让工具查找
候选网页，也可以自己贴链接；判断按需填写。相同链接和你标记为同源的材料会归
为一组。页面只显示：

1. 你添加了多少条材料；
2. 这些材料被归为多少个来源组；
3. 哪些材料被放在同一组。

它不预测收益，不计算目标价，不给买卖评级，也不证明投资判断正确。

## 核心任务

8 篇文章仍然可能只来自 1 个来源，因为它们可能都在转述同一份财报、同一组
数据、同一次采访或同一转载链。链接数量不等于来源多样性。

Falsifi 只做一件事：

```text
你确认加入的材料
→ 相同链接和你确认的同源关系
→ 来源组
```

产品没有固定操作顺序。进入页面后，你可以自己选择添加材料、修改判断或查看
来源组。行情和复核设置不会影响归组结果。

## v0.7 的关键变化

- **首页只说一件事**：不再把产品包装成通用股票分析平台。
- **操作由用户决定**：添加材料、修改判断和查看来源组随时可用，不再强制顺序，
  也不会自动弹出下一张表单。
- **用户主动搜索材料**：只有点击“帮我找材料”才会搜索。结果默认不勾选，并
  标为“待核对”；用户确认前不会写入记录。A 股优先显示巨潮资讯的公司公告，
  并用 Yahoo Finance 补充公开新闻。
- **结果不依赖主观打分**：页面直接显示材料数、来源组数和归组材料数，不要求
  用户填写 0–100 的影响或可信度数字。
- **相同链接不会被拆开**：常见跟踪参数、网页片段、主机名大小写和末尾斜杠
  不会让同一链接变成多个来源。用户可以把更多材料归在一起，但不能把相同链接
  拆成多组。
- **行情只是可选背景**：自动行情不计入用户材料；行情不可用也不影响来源归组。
- **添加材料更简单**：填写标题和链接后，还可以选填发布方、日期、核查
  状态和同源关系。尚未核查的材料会明确标出。
- **次要内容不抢位置**：判断、材料和来源组放在主页面，行情等信息放在次要位置。
- **四语教程重写**：英语、简体中文、日语和西班牙语解释同一个任务与边界。

## 哪些材料会归为一组

以下情况会让材料进入同一来源组：

- HTTP(S) 链接去掉常见跟踪信息后相同；
- 记录的原始来源标识相同；
- 用户明确标记两条材料来自同一来源。

共享同一事实主张或逻辑依赖不会让两个来源自动合并；不同发布方可以独立核实
同一事实。

比较链接前，系统会去掉常见跟踪参数和网页片段，统一主机名并处理末尾斜杠。
可能指向不同文件的有效参数会保留。分成不同组不代表这些来源一定彼此独立，
系统也不能找出互联网上所有转载关系。

示例：

```text
人工加入同一链接 8 次
→ 8 条材料
→ 1 个来源组
→ 7 条归入已有组
```

## 基本用法

- 搜索美股、A 股或港股上市公司。
- 让工具查找候选网页，或自己贴链接。
- 打开候选网页核对，只选择需要保留的材料。
- 如果有需要，再写下你的判断。
- 如果两条材料来自同一份文件、同一组数据、同一次采访或同一转载链，把它们
  关联起来。
- 查看来源组；如果归组不对，随时修改。

削弱条件、反方材料和复核日期可以帮助研究，但都是选填项，不影响来源归组。

巨潮资讯为 A 股提供公司公告候选，系统会核对公告中的股票代码，并只返回官方
PDF 链接。Yahoo Finance 提供延迟行情和补充新闻搜索。搜索会发送必要的公司名、
股票代码和搜索词，但不会发送用户判断。两种来源都可能暂时不可用，也不构成
完整公告库或新闻库；加入前仍需查看原文。详见
[DATA_SOURCES.md](./DATA_SOURCES.md)。

## 诚实的产品差异

投资判断记录、来源链接、AI 研究工具和出处追踪都有现成产品。Falsifi 不声称
“世界首创”“全球唯一”或“从未有人做过”。它现在只专注于：

```text
相同链接放在一起
+ 用户确认的同源关系
+ “材料数 → 来源组数”的直接结果
```

这只是产品定位，不代表其他公开、私有或未公开工具没有相同功能。完整说明见
[docs/UNIQUENESS.md](./docs/UNIQUENESS.md)。

## 隐私与免责声明

当前判断和复核记录默认保存在浏览器中，除非用户导出文件；网站不连接券商，
无需账户，也不做遥测。

Falsifi 仅用于教育、研究记录和证据结构检查，不构成投资建议、证券推荐、
价格预测、适当性评估或交易执行。归组结果只描述用户提供的材料，不证明事实
真实、材料优质、来源统计独立或未来收益。投资可能损失本金。
