# Falsifi

> **查看一项股票判断的材料如何按来源归组。**

Falsifi 是一个开源的股票判断证据核查工具。用户选择一只上市股票，写下一项
具体判断，再加入支持或削弱它的材料。系统会合并相同规范化网址和用户明确
声明的关联关系，然后只回答四件事：

1. 当前记录中有多少项人工录入材料；
2. 当前记录识别出多少个来源组；
3. 其中多少项与已有材料同源；
4. 下一项最应该补充的研究任务是什么。

它不预测收益，不计算目标价，不给买卖评级，也不证明投资判断正确。

## 核心任务

8 篇文章仍然可能只来自 1 个来源，因为它们可能都在转述同一份财报、同一组
数据、同一次采访或同一转载链。链接数量不等于来源多样性。

Falsifi 把这个问题收敛成一条流程：

```text
选择一只股票 + 写下一项判断
→ 提前定义什么会削弱它
→ 添加原始披露和反方材料
→ 合并相同网址和明确声明为同源的材料
→ 显示当前记录识别的来源组
→ 指出下一项缺失的研究行动
```

首页只有股票、判断和一个主按钮。行情图、评分、情景滑杆、关系审计和历史
记录不再占据产品主线。

## v0.6 的关键变化

- **首页只说一件事**：不再把产品包装成通用股票分析平台。
- **每个状态只有一个主要操作**：依次完成定义判断、添加材料和检查来源结构。
- **主结果不再依赖主观分数**：直接显示材料数、当前识别的来源组数、归组材料数和
  下一项缺口。普通表单不再要求用户随意填写 0–100 的影响或可信度数字。
- **强制规范化网址归组**：跟踪参数、网页片段、主机名大小写和末尾斜杠无法
  把同一文件伪装成不同来源。用户可以声明更多关联，但不能把相同网址拆开。
- **行情永远只是可选背景**：自动价格观察不能满足原始披露、反方证据或来源
  多样性检查；行情不可用或历史不足也不会阻断证据核查。
- **证据录入更简单**：只记录事实、发布方、链接、日期、方向，以及是否与
  另一项材料共享底层来源，并明确选择核查方式。未核查材料会保留，但不能
  完成复核门槛；重要性分类使用普通语言而非任意百分比。
- **单列渐进展示**：判断内容、材料关系和简要行情背景都在一条纵向路径中，
  次要信息默认折叠。
- **四语教程重写**：英语、简体中文、日语和西班牙语解释同一个任务与边界。

## 归组规则

以下关系会把材料放入同一关联来源组：

- 相同的规范化 HTTP(S) 网址；
- 相同的已记录原始来源标识；
- 用户明确声明与另一项材料共享底层来源。

共享同一事实主张或逻辑依赖不会让两个来源自动合并；不同发布方可以独立核实
同一事实。

规范化网址会删除常见跟踪参数和网页片段、统一主机名、处理末尾斜杠，同时
保留可能用于识别不同文件的有效查询参数。系统不会宣称不同来源组已经经过
统计独立性检验，也不能发现互联网上全部转载链。

示例：

```text
人工加入同一规范化网址 8 次
→ 8 项人工录入材料
→ 1 个当前识别的来源组
→ 7 项与其他材料归组
```

## 使用流程

1. 搜索美股、A 股或港股上市公司。
2. 写下一项具体股票判断。
3. 写明哪项可观察事实会削弱它，并设置未来复核日期。
4. 加入你实际阅读过的公司或监管机构原始文件。
5. 加入一条可信、会削弱判断的事实。
6. 若材料来自同一文件、数据集、采访或转载链，明确把它关联到已有材料。
7. 阅读当前识别的来源组，完成页面显示的唯一下一项操作。

Yahoo Finance 延迟行情只提供简要背景。该适配器没有官方稳定接口文档，只适合
个人或自托管评估，不适合直接运营公开商业行情服务。详见
[DATA_SOURCES.md](./DATA_SOURCES.md)。

## 诚实的产品差异

投资判断记录、失效条件、AI 多空分析、提醒、决策历史、原始来源链接和情景测试
都有现成产品。Falsifi 不声称“世界首创”或“全球无人做过”。

本轮公开产品审查中没有发现把以下组合同时作为个人股票研究核心任务的产品：

```text
同源关系归组
+ 规范化网址防拆分
+ “材料数 → 当前识别来源组数”的首要结果
+ 确定性的下一项证据缺口
```

这是有边界的市场定位，不代表不存在私有或未公开的同类系统。完整对照见
[docs/UNIQUENESS.md](./docs/UNIQUENESS.md)。

## 隐私与免责声明

当前判断和复核记录默认保存在浏览器中，除非用户导出文件；网站不连接券商，
无需账户，也不做遥测。

Falsifi 仅用于教育、研究记录和证据结构检查，不构成投资建议、证券推荐、
价格预测、适当性评估或交易执行。归组结果只描述用户提供的材料，不证明事实
真实、材料优质、来源统计独立或未来收益。投资可能损失本金。
