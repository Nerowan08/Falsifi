# Falsifi

> **找出什么变化会推翻你的判断。**

Falsifi 是一个开源、来源可追溯、本地优先的股票研究复核工具。它不生成
“买入/卖出”信号，而是把研究案例变成可计算结构，测试哪些变化会改变当前
判断，并保存当时的完整状态供日后复盘。

## v0.5 的核心能力

- **真实股票入口**：首次打开直接搜索或输入美股、A 股和港股，不再默认展示
  虚构公司。
- **行情只是研究背景，不是自动生成的投资判断**：读取约一年延迟日线，分别显示行情时间、获取时间和
  数据来源，并计算区间涨跌幅、年化波动率、最大回撤、Wilder RSI、均线和
  最新成交量相对 20 日均量。完整复权序列可用时使用复权收盘价，否则整段
  使用普通收盘价；页面会标明实际口径。行情指标只用于帮助开始研究，不能
  让案例自动变成“完整研究”，也不预测收益。至少需要 200 个有效日度数据点。
- **研究完整度检查**：只有在用户写明可证伪的研究判断、可观察的失效条件，
  并补充原始资料、反向证据、足够多样的来源和下次复核日期后，案例才会标为
  “可以复核”。页面会明确指出当前缺口，并给出下一项研究行动。
- **关联证据组检查与去重计分**：按共同原始来源、共同研究主张或显式依赖
  关系归组。同一关联证据组内已启用证据先取平均贡献，再与其他组相加，因此
  重复录入同一来源不会放大该组的评分贡献。不同组不代表已经过统计独立性
  检验；是否正确声明关系仍由用户负责。
- **改变判断的最小已测试条件**：按关联证据组整组剔除，寻找能让规则评分
  跨过判断阈值的最小已测试组合。
- **双因素临界组合**：在设定范围内同时改变两个情景参数，返回距离当前案例
  较近、能够跨过阈值的组合。
- **三种证据处理方式**：分别测试剔除证据、将可信度权重减半、以及反转
  证据方向。
- **剔除后评分变化**：逐条剔除证据并重算规则评分；它不是因果估计或回测。
- **单因素敏感性分析**：保持其他参数不变，寻找单个参数跨过判断阈值所需的
  最近变化。
- **来源类型剔除与时效检查**：按公司公告/监管文件、管理层披露、市场数据
  或第三方估算等类别剔除，并标出超过设定时间未更新的证据。
- **本地证据清单**：可新增、编辑、停用、搜索和删除证据，无需账户。
- **可恢复 SHA-256 快照**：为规范化案例 JSON 生成本地内容指纹。它不是
  可信时间戳或防篡改账本。
- **基准变化与下一步行动**：对比当前行情背景和最近一次已保存快照，指出
  变化、当前最薄弱的已测试条件和证据缺口，并转成一项具体的后续研究任务。
- **四种界面语言**：英语、简体中文、日语和西班牙语。自动生成的案例采用
  当时所选语言；用户自己写的研究文字绝不会被静默翻译或覆盖。
- **内置完整使用指南**：顶栏和选股页都能进入四语教程，说明数据口径、
  操作步骤、测试边界、本地存储与常见问题。
- **本地优先工作区**：无需数据库、券商账户、用户账号或遥测；加载行情时
  需要联网。

## 用 Falsifi 处理一个真实研究问题

1. 选择美股、A 股、港股或全部市场。
2. 搜索公司名称，或输入 `AAPL`、`603901`、`002441`、`0700.HK`
   等代码。
3. 选择公司后，Falsifi 会把延迟日线作为**行情背景**载入。当前仅接受至少
   有 200 个有效日度数据点的上市股票；ETF、指数、期货、外汇和加密资产
   会被拒绝。
4. 写下你真正要验证的判断、时间范围、一个可观察的失效条件，以及下次复核日期。
5. 加入监管文件、公司公告等原始资料，并刻意补充反向证据。若几条证据来自
   同一来源或支持同一主张，应把它们声明为同一关联证据组。
6. 按研究完整度清单补齐来源多样性。计算结果只用于检查判断，不是下单许可。
7. 保存一次基准。下次复核时刷新行情，查看哪些背景指标已经变化，测试最薄弱
   条件，并完成页面建议的下一项研究行动后再更新判断。

内置 Yahoo Finance 图表/搜索适配器没有官方稳定 API 文档，仅适用于个人或
自托管评估，可能延迟、限流或被上游修改。若公开运营商业数据服务，应替换
为已取得展示/再分发授权的数据商。详见 [数据源边界](./DATA_SOURCES.md)。

机器可读结构在
[`data/case.schema.json`](./data/case.schema.json)，入门模板在
[`examples/case-template.json`](./examples/case-template.json)。

## 计算边界

同一份有效案例 JSON 与同一引擎版本会产生相同结果：

- 关联证据组剔除测试在最多四个组的范围内做精确枚举；
- 同一关联证据组内的证据贡献采用平均值，重复录入同一来源不会让该组重复加分；
- 双因素搜索在 100,000 个状态以内做穷举，超过后采用确定性降采样，并在结果
  中保留相应元数据；
- “未找到判断变化”只表示测试范围内未找到，不代表研究判断真实或绝对稳健。

完整公式与边界见 [`docs/METHODOLOGY.md`](./docs/METHODOLOGY.md)。

## 可选的 SEC 官方数据

SEC API 无需密钥，但必须提交带联系方式的 `User-Agent`：

```bash
export SEC_USER_AGENT="Falsifi research you@example.com"
npm run sec:fetch -- --ticker AAPL --output outputs/sec/aapl.json
```

脚本保留 XBRL 标签、单位、报告期、表格类型、accession number、提交日期和
SEC 原始链接；默认不抓交易所网站，也不重新分发第三方行情。

## 关于产品差异

图表、提醒、筛选器、投资判断记录、场景分析、反事实解释、证据清单和
SHA-256 内容指纹都有成熟替代方案，Falsifi 不声称发明了其中任何一项。
它较有竞争力的地方，是把一组在主流个人投资工具中并不常见的能力连成
一条实用工作流：

```text
可证伪判断 + 失效条件
→ 研究完整度检查
→ 关联证据组去重
→ 改变判断的最小已测试条件
→ 相对已保存基准的变化
→ 下一项研究行动
```

仅仅展示行情摘要或自动指标，很容易被图表网站、电子表格、笔记工具或通用
AI 助手替代。Falsifi 真正有用的场景，是用户需要记录“为什么形成这个判断”、
防止把重复信息当成多份支持，并明确“出现什么变化就应该重新检查”。它不是
“全球首创”或“独一无二”的产品。对照产品、公开先例和本轮实际产品审计见
[`docs/UNIQUENESS.md`](./docs/UNIQUENESS.md)。

## 明确不做什么

- 不提供个性化投资建议或适当性判断
- 不给出买入/卖出评级或目标价
- 不连接券商或自动交易
- 不承诺收益、准确率或 alpha
- 不把研究分数包装成客观概率
- 不用自动翻译覆盖用户的原始研究文字
